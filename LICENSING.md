# FND Reverb licensing status

A project-wide license for FND Reverb is pending review. This statement does not grant a license to copy, modify, or redistribute the project. Any permissions already applicable to individual components remain governed by their own terms.

## Source and releases

- **Source:** The repository is publicly viewable. A project-wide open-source license has not been declared.
- **Release packages:** The macOS and Windows archives attached to `v0.2.5` are available from [GitHub Releases](https://github.com/stancsz/fnd-reverb-vst3/releases/tag/v0.2.5). Permission for third parties to redistribute or repackage those archives has not been confirmed.
- **External registries:** If your registry requires a license or redistributes downloads, contact the maintainer in [issue #28](https://github.com/stancsz/fnd-reverb-vst3/issues/28) for an update on the review.

## Dependencies

The default CMake build fetches [JUCE 8.0.4](https://github.com/juce-framework/JUCE/tree/8.0.4) when JUCE is not already available. JUCE is subject to [its own licensing terms](https://github.com/juce-framework/JUCE/blob/8.0.4/LICENSE.md). The terms for JUCE and other third-party materials are unaffected by this statement. A license decision for the plugin must account for the dependency versions and third-party material included in each release.
